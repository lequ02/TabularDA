# AAAI 2027 manuscript draft

Open `paper.tex` to edit the manuscript. The rendered PDF is `D:/SummerResearch/output/pdf/aaai27_relabeling/paper.pdf`. It uses the anonymous AAAI 2027 submission template supplied in `papers/AuthorKit27.zip`; `aaai2027.sty` and `aaai2027.bst` are unchanged.

The draft contains section headers, two wide real-data results tables, classification and regression contrast tables, a known-distribution results table, a Bayesian-network schema table, and a short simulated-data construction section with two vector figures. Unwritten prose is left as source comments. The earlier storyboard, outline, per-dataset layouts, and method-by-method joint-minus-X-only tables are historical artifacts excluded from the current source package.

The two main real-data tables use datasets as columns and methods as rows, with separate tables for synthetic-only and mixed training. Each has classification and regression panels, grouped dataset headers, and an individual column for each metric. Generated-target CTGAN/TVAE/TabDDPM baselines appear above a horizontal separator; features-only generation followed by RF/XGB/DNN appears below it. Space separates generator families. Scores are means over seeds 42/43. Bold marks the best displayed two-seed mean; underline marks the second-best distinct mean. Ranking includes real-only data and ties at the reported precision. Partial entries are marked with daggers and excluded from ranking. Underlining uses the standard LaTeX command and requires no extra package.

The real-data tables span both columns using the template's `table*` environment. The supplied author instructions explicitly require a double-column layout when a table does not fit a single column. Their bodies and captions use 10-point type, without scaling. RF/XGB/DNN are labelers; neural networks evaluate downstream utility. Dataset-specific metrics and full-precision score sources are retained. Regression reports R² and D² absolute error, both higher-is-better. D² equals one minus test MAE divided by the constant test-median baseline MAE. CTGAN/TVAE D² values come from the hash-verified frozen derived-score file. The six completed TabDDPM Housing records were scored from saved predictions on the research server, with targets, source IDs, record hashes, MAE, and R² checked; `tabddpm_d2_snapshot.json` stores the evidence. Server files and the original records remain unchanged. Per-seed values and records are retained in `tables/cell_provenance.json`; main-table means are in `tables/summary_provenance.json`.

The contrast tables reuse the verified `output/statistical_two_contrasts_20261010` effects. Exactly two contrasts are reported: relabeled minus generated, and joint minus X-only. The first averages both relabeled feature sources; the second compares them with predicted targets in both arms. CTGAN/TVAE, RF/XGB/DNN, and seeds 42/43 receive equal weight. Classification uses macro F1 on each of the five tasks, then tests the five dataset contrasts with exploratory two-sided paired t tests (df=4). Its table reports raw p-values and pointwise 95% confidence intervals, with no multiplicity adjustment. TabDDPM is excluded from the contrasts. Saved contrast means were checked against the frozen scores; `tables/contrast_provenance.json` preserves the source hashes, selected raw tests, and task effects. The existing statistical reports remain unchanged.

Table 5 adds 16 unadjusted, two-sided paired permutation p-values for News and Housing, with separate R² and D² panels. All 112 CTGAN/TVAE regression records, derived D² sidecars, prediction hashes, held-out targets, and source-ID order were verified on the research server. Both experiment seeds share the same test cases: 7,929 News rows and 4,128 Housing rows, with no duplicate feature groups. Squared and absolute errors are averaged across the specified fixed fits before forming each paired contrast; predictions are not averaged into an ensemble. Reductions in these losses reproduce the saved R²/D² gains. Each of 99,999 permutations flips one sign per feature group, shared across fits, seeds, regimes, and metrics. The raw two-sided p-value is `(1 + number of absolute permuted means at least as large as the absolute observed mean) / 100000`; the inference RNG seed is 20261011. Values below 0.0001 are displayed as `<0.0001`, never zero. The null assumes independent feature groups with sign-exchangeable aggregate loss contrasts. These are exploratory tests conditional on the fitted models and concern held-out-case variability, rather than variation from retraining or across datasets. `statistics/` contains the remote calculation script, frozen-input requests, full-precision results, grouped loss contrasts, execution record, and focused independent checks. No training or generation was run.

CTGAN/TVAE tables cover the complete selected seven-task grid (406 records). TabDDPM is a partial snapshot from October 11, 2026, 00:25 Chicago: four real-only references and five Housing synthetic/mixed results. Dashes represent unfinished entries. Rows with no completed scores are omitted; captions record that TabDDPM X-only results and matched pairs are unavailable. The remote record hashes, saved models and predictions, and canonical held-out partitions were checked; see `tabddpm_verification.json`. No experiments were launched for this draft.

The simulated results use the separate seven-task, two-seed benchmark (378 evaluations). The Gaussian/Grid/Ring visualization redraws the same saved original-process points and Bayes boundaries as the supplied image. Its seed-7 illustration has 2,000 rows per dataset; these are independent of the production benchmark's 10,000-row draws with seeds 42/43. It is an illustration of the process, not a smoke-run performance result. The Asia graph is read from the packaged BIF. Markers distinguish target classes in grayscale.
