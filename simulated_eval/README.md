# Known-distribution simulated benchmark

This directory is independent of SDGym, SDGym-research, and the existing labeler code.
It contains a new data-generating process, not a reproduction of the CTGAN paper's simulated experiments.

## Distribution

The table has four columns:

- `feature_0` and `feature_1`: independent standard-normal variables X0 and X1.
- `feature_3`: binary category C, drawn with probability sigmoid(kappa * X0 * X1).
- `target`: the clean target h* with an independent Bernoulli(noise) label flip.

The clean target is:

    h*(X0, X1, C) = 1[X1 + (1 + beta * (2C - 1)) * X0 > 0]

Defaults: kappa=2, beta=0.75, noise=0.10. The category changes the coefficient of X0
from 0.25 to 1.75. Both continuous features and the category affect the clean boundary.
The noise is independent of all features; it is not generated by the classifier.

The exact joint density is:

    p(x0, x1, c, y) = phi(x0) * phi(x1)
                     * a^c * (1-a)^(1-c)
                     * r^y * (1-r)^(1-y)
    a = sigmoid(kappa * x0 * x1)
    r = noise + (1 - 2*noise) * h*(x0, x1, c)

`Oracle.log_prob` calculates this in log space, without density fitting, clipping,
or epsilon probability floors. Its measure is Lebesgue measure for X0/X1 and counting
measure for C/Y. All finite continuous values and binary combinations are supported.

## Mathematical properties

1. X0 and X1 are independent by construction.
2. C is dependent on (X0, X1), but marginally independent of either alone:
   sigmoid(t) + sigmoid(-t) = 1 and normal symmetry imply
   P(C=1 | X0=x0) = P(C=1 | X1=x1) = 1/2.
3. For noise < 1/2, h* is the Bayes-optimal classifier. Its population accuracy
   against noisy targets is 1-noise. A finite test accuracy can exceed that expectation.
4. Simultaneously negating X0 and X1 preserves the feature/category distribution
   and negates the decision score. The score is zero with probability zero, so both
   the clean and noisy target are balanced in the population.
5. For any fixed classifier h on independent test rows:

       P(h(X) != Y) = noise + (1 - 2*noise) * P(h(X) != h*(X)).

   Thus agreement with h* separates decision-boundary error from irreducible noise.

## Methods

The default run has 27 methods per seed:

- `original`: train a fresh evaluation DNN on samples drawn directly from the known process.
- `ctgan`, `tvae`: generate the complete four-column table, retaining generated targets.
- `{generator}-joint-{labeler}`: reuse that generator's three feature columns and replace targets.
- `{generator}-features-{labeler}`: train a separate generator on the three feature columns,
  then assign targets with the labeler.

The six labelers are `gaussian`, `categorical`, `pca_gmm`, `rf`, `xgb`, and `dnn`.
All are fitted once per seed on original training features and **noisy** targets.
All assign hard predicted labels; they do not simulate independent target noise.
Consequently, high prediction utility does not imply preservation of the noisy joint distribution.
Within a source group, the features are identical across labelers; only targets change.
Joint likelihood includes targets and can therefore distinguish relabeling variants.

- Gaussian NB models all three features with Gaussian class-conditional factors.
- Categorical NB quantile-bins only the two continuous features into ten bins. The binary
  category stays binary. Bin boundaries are fitted on original training data.
- PCA-GMM standardizes training features, projects to two PCA components, and fits a
  four-component full-covariance Gaussian mixture per class with empirical class priors.
- RF uses 100 trees.
- XGB uses 100 depth-six trees and learning rate 0.1.
- DNN is a standardized sklearn MLP with two 64-unit hidden layers. Early stopping uses
  an internal 10% original-training validation split, never the test set.

These are standalone implementations; their results are not asserted to reproduce the older labelers.

## Metrics

Every synthetic table gets the same evaluation:

- `joint_log_likelihood`: mean exact original joint log density on its synthetic rows.
- `accuracy`: a fresh standardized DNN trained on that table predicts noisy targets in the independent test set.
- `macro_f1`: unweighted mean F1 over target classes 0 and 1 for those same predictions.
- `h_star_agreement`: the same DNN predictions compared with the clean targets on the same test features.

The original baseline uses its original training table instead of a synthetic table.
The original test set is sampled independently and reused across methods within a seed.
Every evaluation DNN has two 64-unit hidden layers and the same training procedure as
the DNN labeler, but is initialized and trained separately on its own input table.
Its scaler and internal early-stopping validation split use only that training table.
RF is used only as a labeler in RF variants, never as the final evaluation classifier.
Original-table likelihood is evaluated with the fixed analytical density, not a model
fitted to that table; it estimates E_P[log p(Z)] and is a reference rather than a maximum score.
This likelihood is L_syn-style, not L_test: CTGAN supplies no explicit density, and we do
not introduce another fitted density evaluator. Mean joint likelihood alone cannot establish
that a generated distribution equals the original; concentration in high-density regions can improve it.

## Run

From the repository root, in an environment containing the dependencies in requirements.txt:

```powershell
python -m simulated_eval --output output/new_simulated_eval --device cpu
```

Defaults: two seeds (42,43), 10,000 original train/test rows, 10,000 synthetic rows,
300 epochs per generator/source, batch size 500. For CUDA, explicitly pass `--device cuda`.
The device flag applies to CTGAN/TVAE; sklearn labelers and the evaluation DNN run on CPU.

Small execution check (not a quality experiment):

```powershell
python -m simulated_eval --output output/new_simulated_smoke --seeds 7 --train-rows 600 --test-rows 300 --synthetic-rows 600 --epochs 1 --batch-size 100
```

Use `--labelers` with no following values to run only generator baselines; use
`--labelers rf xgb` to select a subset. Generator selection uses `--generators ctgan tvae`.
The output directory must not already exist. There is no cache reuse, resume path, backup,
automatic device selection, or fallback generator. Failures are surfaced directly.

Outputs: config.json (parameters and package versions), per-seed train/test/source/synthetic
CSV tables, per_run.csv, summary.csv (seed means and sample standard deviations),
comparison.png and comparison.svg. Plot circles show individual seeds and their means;
the accuracy panel marks the best expected accuracy 1-noise. Each panel has vertical
CTGAN and TVAE baseline-mean references (dashed and dotted respectively). Colors distinguish
the process-sampled baseline, generator baselines, joint-generation relabeling, and features-only relabeling.

Verification:

```powershell
python -m pytest simulated_eval/test_benchmark.py -q
```
